安卓 / 苹果安装方法
安卓（Chrome / Edge / 三星浏览器）
  1. 把本文件夹放到任意静态托管（GitHub Pages、Netlify Drop 都能免费一键部署），拿到 https:// 网址
  2. 手机浏览器打开该网址
  3. 点右上角菜单 → 「安装应用」 或 「添加到主屏幕」
  4. 桌面出现「燃练」图标，全屏打开、断网也能用
苹果 Safari
  1. 用 Safari 打开网址
  2. 点分享按钮 → 「添加到主屏幕」
想变成真正的 .apk
打开 PWABuilder.com，粘贴你的 https 网址，选择 Android 打包，即可下载签名好的 APK／AAB 安装包。
怎么使用动作库
添加动作
在「动作库」点击「从常用动作中选择」，按热身、胸、背、腿等分类挑选动作，点「加入动作库」即可保存。也可以点击右下角「＋」手动创建自己的动作。

安排训练
动作加入动作库后，点击「加入今日」即可排入当天训练清单；训练过程中可以记录组数、次数和重量。

数据保存
所有动作和训练记录保存在当前设备浏览器本地。更换手机前，请先导出 JSON 备份。
关于燃练
燃练 RepLog · 训练与饮食管理版
一个简洁的健身工具：从常用动作库中挑选动作，整理成能真正执行的训练清单。

所有数据保存在你自己的手机本地（localStorage），不上传任何服务器。换手机时用「导出／导入」搬数据。

选择常用动作

选择适合自己的动作，加入后可在动作库中安排今日训练。

添加动作

创建自己的训练动作。常用动作可在动作库中直接选择添加。
可上传动作照片或示范截图；不上传时会自动生成对应动作示意图。
