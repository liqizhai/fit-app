装到手机
安卓 / 苹果安装方法
安卓（Chrome / Edge / 三星浏览器）
  1. 把本文件夹放到任意静态托管（GitHub Pages、Netlify Drop 都能免费一键部署），拿到 https:// 网址
  2. 手机浏览器打开该网址
  3. 点右上角菜单 → 「安装应用」 或 「添加到主屏幕」
  4. 桌面出现「燃练」图标，全屏打开、断网也能用
苹果 Safari
  1. 用 Safari 打开网址
  2. 点分享按钮 → 「添加到主屏幕」
想变成真正的 .apk
打开 PWABuilder.com，粘贴你的 https 网址，选择 Android 打包，即可下载签名好的 APK／AAB 安装包。
怎么把抖音视频搬进来
一键搬运流程
  1. 抖音视频页 → 分享 → 复制链接
  2. 回到燃练 → 点右上角 ＋ → 把整段分享文案粘进去
  3. 点 「提取链接」，链接和平台自动识别
  4. 填标题、选部位，保存 —— 教程就进库了
为什么只存链接？
视频版权归创作者，直接下载搬运会侵权。燃练只保存链接 + 你自己的训练笔记（组数、要点、感受），点「观看」跳回原视频，这样既合规又能长期用。

想离线看？在抖音里把视频收藏／下载到相册，再把要点写进教程备注，训练时看备注就够用了。
关于燃练
燃练 RepLog · v1.0
一个只做一件事的健身工具：把你在各个平台刷到的动作教程，整理成能真正执行的训练清单。

所有数据保存在你自己的手机本地（localStorage），不上传任何服务器。换手机时用「导出／导入」搬数据。
